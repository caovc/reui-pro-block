## Actual free reuse

- Real `Frame`, header/title/description/panel/footer and `Badge` provide the board, detail sections, count and semantic status surfaces. Their token/radius/spacing behavior remains intact; there is no substitute Frame/Badge implementation.
- Canary traffic directly consumes the installed native `Slider`, following the actual official free `c-slider-5` controlled-value composition and `c-slider-10` tick-label composition. Five domain positions map to 0/5/25/50/100 percent. Native Slider owns pointer capture, touch, arrow/Home/End handling, focus and disabled state. There are no custom pointer/keyboard handlers or hidden replacement input. The consumer refuses an unarmed zero request and sends an armed request to the native rollback AlertDialog, leaving real traffic unchanged until confirmation.
- Operator confirmations consume the actual ReUI Alert/Title/Description/Action anatomy inside the modal, so Undo remains reachable by pointer and keyboard while native outside interaction stays inert. The global Sonner toast remains available after closing the Sheet.
- The release log consumes real ReUI Timeline anatomy. The original `c-timeline-6` and `c-timeline-10` patterns were also inspected; the existing Frame and status Badge are composed with Timeline entries instead of drawing a replacement timeline engine.
- ReUI `IconTile` and `IconStack` provide meaningful service and empty surfaces. Checks and change summaries consume the existing Item anatomy. The existing official free `useCopyToClipboard` hook is imported from `application/empty-variants/team-setup/free`; it is not duplicated or modified.
- Native Sheet, Tabs, AlertDialog, Select, Toggle, Tooltip, InputGroup, Avatar and Table provide focus, portals, menus and content structure. The board is a status wall with no column sorting, selection, resizing or pagination, matching the public Table composition; it does not recreate any DataGrid engine. Adding such capabilities later must use the already-installed actual ReUI DataGrid.

ReUI MIT, shadcn MIT and font OFL attribution remain in the transitive source/export closure. The leaf imports the existing reference Inter CSS and applies `reui-reference` to its Sheet, AlertDialog, Select and Tooltip portals. New dependencies, global CSS and shared primitives are untouched.

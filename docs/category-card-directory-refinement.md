## Actual official free reuse

Sources and existing consumers were inspected before implementing the new leaves.

- [`c-card-8`](https://reui.io/r/radix-nova/c-card-8.json): all three leaves actually import the already frozen `shop-hero-variants/image-card.tsx`. Its real Card, absolute image, image zoom, fade and content composition remain consumed source, with domain dimensions/children. No new image-card primitive is introduced.
- [`c-scroll-area-1`](https://reui.io/r/radix-nova/c-scroll-area-1.json): `featured-department.tsx` keeps the real ScrollArea → padded header/content → divided list structure and native viewport/scrollbar. Height is adapted to the public 620px desktop brief; domain rows use existing Item rather than hand-built scroll mechanics.
- [`c-item-4`](https://reui.io/r/radix-nova/c-item-4.json): the directory uses actual ItemGroup, Item asChild, image media, content/title/description, actions and separators. Native buttons replace placeholder anchors to open existing local dialogs; no new focus/pressed/link primitive is added.
- [`c-item-2`](https://reui.io/r/radix-nova/c-item-2.json): guide rows consume real Item, ItemContent/Title/Description and ItemActions anatomy, with the already reused free image-card as their larger domain media. They retain actual native Item implementation rather than a similarly named wrapper.
- [`c-breadcrumb-1`](https://reui.io/r/radix-nova/c-breadcrumb-1.json): all pages reuse the frozen `category-card-variants/breadcrumb.tsx` composition and its real complete-catalog route.
- **Official REUI Badge** is used for the feature and guide signals, and as the fixed outline Badge described by the seasonal brief. No hand-built equivalent badge is added.
- **Existing CollectionBrowser / CollectionSaveProvider** supply all image/row/View/subcategory/Shop/edit navigation, real c-item-2 product rows, c-tabs-9, c-scroll-area-1, c-toggle-10 saved state and REUI Alert/Badge. Counts, starting prices and product detail all describe this same actual sample data. All entry points share saved state; no second catalog/dialog/save implementation is introduced.

## Confirmed custom gaps

The inspected free registry supplies image zoom/fade, native scroll regions, clickable rows, breadcrumbs, badges and local composition capabilities. It does not supply this Bricklane guide taxonomy, unique inventory accounting or collection starting-price derivation. Only that domain data/computation is custom.

The free c-card-8 demonstrates zoom/fade with a persistent caption; it does not include the specific seasonal full-surface rest/detail replacement with mobile-always-open rules. Those small CSS states extend its actual consumed implementation. The inspected official free [`c-hover-card-1`](https://reui.io/r/radix-nova/c-hover-card-1.json) demonstrates a floating trigger panel, which is a different capability and does not replace this full-image surface treatment. Native focus, modal, scroll and save interactions remain existing real free implementations.

## Original media, data and attribution

All images are existing original `wishlistArtwork` drawings. Fictional Bricklane names, copy and status labels intentionally differ from upstream photographs and branding. No original-site avatar, photograph, decorative SVG, paid screenshot, ReUI/KeenThemes logo or favicon is loaded or exported.

The same 60 local original samples power all routes. Department collections are disjoint; broader curated edits overlap. Guide budgets represent the minimum price of one actual piece, not a bundle price or fabricated minimum spend. Official REUI MIT, shadcn MIT, project license and font OFL notices remain included through the existing export pipeline.

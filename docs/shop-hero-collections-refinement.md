## Original media and domain data

The new data module consumes the repository's original `wishlistArtwork` drawings, producing independent clothing, footwear, accessory and home still lifes. Three original color treatments across five seed pieces in each category produce 60 distinct sample entries. No upstream photography, SVG, logo or avatar is loaded. Shape reuse across colorways and footwear styles is an intentional illustration limitation, not a claim of matching reference photographs.

Bricklane names and fictional story copy replace source branding. Category/story labels, review counts and copy remain provisional pending the public rendered comparison. The local catalog lets a viewer search names/materials, filter native tabs, open a piece, save/unsave with the actual free Toggle and return with saved state retained. The saved-piece context is shared across every entry point in one hero, so category navigation and the all-pieces link agree on the same selection. These are documented local extensions over reference navigation placeholders.

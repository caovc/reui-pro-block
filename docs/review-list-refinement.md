## Media and local state

All original avatars come from the existing `demoAvatar` helper and are rendered through AvatarImage. This batch imports no photo, external image URL, upstream SVG media, paid asset or logo. All names, review prose and new highlight paragraphs are fictional original content. The old six unpublished reviewer JPGs were already deleted in the prior milestone; ZIP checks verify they are absent.

Reviews and votes are local demonstration state and reset on navigation/reload. Topic switches preserve mounted review votes. The all-samples dialog uses its own local row instances; it is not a synchronized server view. Aggregate mention counts/percentages retain the public fixture values, rather than pretending six samples represent1284 fetched records. The shared composer explicitly states that no external submission is made.

## Actual free ReUI reuse and custom domain gaps

The official free Data Grid's provider, container, viewport, table/head/body/row/cell/footer primitives, column headers, and now its empty row remain the actual rendered implementation. `DomainGroupedGrid` continues to call the existing `useDomainGrid` adapter, which creates a real `useTable({ features: dataGridFeatures })` instance. Original records reach native accessors, filtering, numeric sorting, column visibility, selection, and expanded-row models. No replacement table or filtering engine was introduced.

Free ReUI Frame/FramePanel and Badge remain in use. Public layouts have no pagination controls or fixed-column controls; this batch preserves those surfaces rather than adding unrelated controls. Roadmap is headerless. Revenue and Cohorts sort through the free component's direct header buttons.

The remaining domain rendering is intentional: category icons, date formatting, progress rings, ARR-weighted retention, renewal roll-ups, heat thresholds, and cohort comparisons are not supplied by a generic Data Grid. Existing `TableOptions` combines density and field visibility in one Display menu; the standalone free column-visibility component has no density entry, so this existing combined-menu adapter is retained. Basic menu/select/switch/HoverCard primitives match the Radix primitives used by the installed free library. These controls write the actual table's state or its domain predicate. Cohort regrouping continues to open newly named bands, preserving the prior local interaction; this differs from the public preview retaining its old expanded IDs.

All shipped portraits come from the repository's original `demoAvatar` helper. No upstream portrait, logo, paid screenshot, or extracted SVG was introduced. The free component MIT and font OFL notices remain part of the actual downloaded starter graph.

## Source and publication scope

The first three entries now have separate default-export leaves: `grid-grouping-roadmap.tsx`, `grid-grouping-revenue.tsx`, and `grid-grouping-cohorts.tsx`. `grid-grouping.tsx` imports those leaves and retains Grouping 4–7. A narrow `source-targets.ts` patch selects each leaf before the family fallback. The primary session owns that shared-file integration and the only Git publication window.

Validation uses a clean archived baseline plus only this batch and the source-target patch. Build information and Vite caches are isolated from the shared workspace. Four regression checks failed on the original production baseline before the fixes: task attributes changing after search and each page's missing native empty row. No old timeout or assertion was relaxed.

They cover Grouping 1–5's existing hierarchy/selection behavior, empty→restore, stable searched attributes, aligned filtered revenue summaries, cohort replacement/regrouping, heat-cell height and comparison, real header sorting, selection through collapse, signal multiselect, and density/visibility. All six desktop/mobile captures have meaningful page content, no framework overlay, no browser or console error, no remote/broken portraits, and no document overflow. Roadmap measurements are 44px group rows and 41px task rows; Cohorts has 44px groups and 56px note rows.

The clean production build, owned formatting/oxlint checks, and two source-graph tooling tests passed.

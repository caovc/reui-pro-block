The free library has no wishlist collection domain store, cover mosaic generator, priority-cycle mutation, saved-inventory database, collection JSON sharing service or email-delivery backend. These specific missing domain capabilities are implemented as local React data transformations and the already documented download/restock helpers. Existing component mechanics are actually reused; no selection, native tab, dialog, avatar image/fallback, frame or quantity-input mechanism is hand-recreated.

## Media, source readability and persistence

All covers and product images use the frozen `wishlist-artwork.ts` original geometric illustrations via `svgImage`; no new remote media or binary asset is introduced. Source remains readable multiline TypeScript, formatted with oxfmt and checked with oxlint. All local edits reset on reload. The shared marker is explicitly described as local, and share dialogs copy a demo URL or export current records rather than publishing user data.

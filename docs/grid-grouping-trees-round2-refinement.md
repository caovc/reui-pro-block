## Actual free ReUI reuse and remaining custom work

BOM continues through `DomainRecordGrid` → `useDomainGrid`; Reporting uses the same `useDomainGrid` adapter and the official DataGrid provider, container, table, cells, headers and footers directly. The adapter creates a real `useTable({ features: dataGridFeatures })` instance. Native filtering, sorting, visibility, row selection and expansion receive the original tree records. Neither leaf implements a replacement table/controller.

Both leaves compose actual free Frame/FramePanel and Badge components. Both compose the official `DataGridScrollArea` for genuine horizontal scrolling; BOM enables a new optional `scrollArea` argument on the existing domain adapter, whose undefined default preserves other consumers. Reporting uses that free scroll component directly. BOM additionally uses the free FrameHeader/Title/Description, IconTile and `DataGridTableRowExpand`. Reporting retains its named expansion button because the installed free expander only accepts global expand/collapse labels; it has no per-row accessible label prop. This small named control calls the actual native row's `toggleExpanded`. Selection checkboxes likewise update the native row state and preserve the existing named controls. They do not replace the selection engine.

Domain quantity/cost/lead/supply roll-ups and organizational counts are absent from the generic free Data Grid, so those functions remain custom. Both Display popovers now compose the installed Field/FieldGroup/FieldSeparator, Select, Switch and Button primitives as shown publicly: density plus part detail or job title, followed by the observed property pills. The standalone free visibility component does not provide those domain controls, so this composition remains consumer-owned while changing the native visibility state. Primitive popovers, dialogs, selects and switches use the same installed Radix composition as the free library. No vendor DataGrid, Filters, shared Tabs or global CSS was edited.

All portraits come from the repository's original `demoAvatar` helper. Icons are Lucide components, not extracted upstream SVGs. No ReUI/KeenThemes branding, upstream portrait, paid screenshot or decoration was introduced. The actual downloadable source graph retains the free ReUI MIT and font OFL notices.

## Deliberate limits

Reporting retains the existing local 18-person fixture to preserve the established eight-person Leo reporting line. The public roster is also 18 people but has five layers/2.1 average span/six openings; displaying those public numbers on the local tree would be inaccurate. Local counts and tree changes are therefore derived honestly and this fixture departure is explicit. Local personnel actions demonstrate state changes, not a backend persistence claim. Reporting's mobile minimum table width remains 1,206px versus the public 1,144px, and desktop Filter/Actions horizontal positions differ by 2–4px; both use real inner scrolling. BOM's mobile table width differs by one pixel because of the native fill calculation. Dialog-title font inheritance is a separately reported shared Theme concern; no local outline or global font workaround is included. These distinctions remain open rather than being described as pixel parity.

Portal measurements additionally exposed narrow 128px action menus that wrapped Copy number and Change manager. The public menus are 176px wide with a separator before the third item; both leaves now pass those actual component parameters. BOM summaries require 12px/16px/500 and `tabular-nums`, whose digit widths determine the public mobile wrapping. Header cells are 14px/20px/500, while their visible native sorting buttons are 14px/20px/400. These were measured separately; the free button's normal weight is preserved.

The official resizable Data Grid adds an aria-hidden footer fill cell. It is not an extra data column: header/body/footer visibility comparisons must exclude that fill cell. Two existing BOM selectors need narrow semantic adaptation: the actual free single-choice ToggleGroup exposes `role=radio`, and the $22.20 check must address the Copper row because filtered ancestor summaries and the footer legitimately show the same value. Assertion values, visibility requirements, timeouts and retry policy remain unchanged.

Tabs consumer checks found no Tabs in Grouping 1/2/4/5. The frozen Cohorts consumer has no vertical content overflow at either size; its narrow viewport has genuine horizontal overflow. A keyboard probe found the last activated tab partly clipped, which was separately reported to the shared Tabs owner. That follow-up is not mixed into the frozen 1–3 release or this tree batch, and real table horizontal scrolling remains intact.

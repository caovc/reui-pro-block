# AppShell accent fidelity review

The reported problem was visible color behavior, not missing global theme state: the customizer already set `--primary` and `--ring`, but several shell consumers kept neutral selection colors, fixed foreground dots, or a local dark primary override.

## Reference and reused foundation

All 36 public previews were rendered at 1280×900 from `https://reui.io/preview/base/app-shell-N?embed=1`. The accent-consumption probe changed root `--primary`, `--primary-foreground` and `--ring` to violet, disabled transitions, and waited for two animation frames before comparing computed colors. It records actual consumption of these tokens; it does not claim to have exercised every setting in ReUI's site customizer. Evidence stays outside the repository in `/tmp/appshell-theme-reference.json`.

The existing actual free c-sidebar-1/c-sidebar-2/c-sidebar-3, SidebarProvider, Header/Footer, Menu/SubMenu, responsive Sheet, Tree, Tabs, Calendar, Badge and Button dependencies remain in use. The free c-sidebar-1 registry source was checked again at `https://reui.io/r/radix-nova/c-sidebar-1.json`. Inventory's remaining hand-built application buttons and section rows were replaced by the actual shared ReUI SidebarNavigation composition, preserving names, section changes, counters and the existing mobile close behavior.

Global theme settings remain owned by the existing site store. No shared UI dependency, global theme store or theme-token implementation is changed.

## Validation

The corrected fixed production build passed the full 100-case AppShell/global-theme/site/source suite in 3.1 minutes. The final route-specific color additions and retained assertions passed all 13 final production theme tests in 44.0 seconds. Exact logs are recorded in the release manifest. The first run's 99-pass/1-fail record is retained: ScopePanel composes ReuiSidebar directly and initially missed the responsive wrapper's theme class. The fix adds a precisely scoped parent-variant rule, without relaxing its color assertion.

Actual UI downloads for AppShell 18 and 8 contain 371 files each. Eight owned implementation/style modules match candidate bytes; default Code, Copy and single-file download match the actual productivity/inventory leaves. Both original ZIPs independently compile. Starter downloads intentionally retain the default theme: the existing SourcePanel separately provides “Theme CSS · current customization” and instructs appending it after starter CSS and applying the dark root class. The actual emerald CSS artifact was downloaded through that control and appended unmodified for separate standalone rendering/build checks. This is not a claim that ZIPs automatically save the current preset.

Desktop emerald, dark violet, original mark ink, selected badges/progress and phone navigation were visually inspected. Runtime and console inspection was clean. Browser plugin is not available in this session; validation uses Playwright Chromium. Format checks pass. Scoped oxlint has no errors; mixed component/helper exports remain warnings, including the context export in the existing chrome module. Checks exercise light/dark emerald/violet, custom HEX, actual catalog Customize → iframe updates without clearing selected navigation, reset, collapsed desktop → phone navigation, Escape/focus return, native application section selection, selected rail hover, ring-colored controls and preserved status/tag colors. Existing geometry and product interaction suites are retained.

This does not certify every nested product workflow or all-browser pixel equality. Product fixtures, the original Bricklane mark and licensed/local artwork remain custom because those product-specific contents are not supplied by the free navigation components.

Final standalone evidence: both final 371-file UI downloads plus the unmodified actual emerald CSS artifact passed independent TypeScript/Vite builds. The exported task shell retained theme-colored Today selection, native 66px collapse, dark-root phone labels and Escape/focus return. The exported inventory shell retained the actual free menu section workflow and emerald active color. Runtime/console errors were empty.

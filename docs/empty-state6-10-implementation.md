## Concrete free-source reuse map

- **Empty composition:** all20 official free `c-empty-1…20` examples were inspected. Free `c-empty-1/4/8` actually import upstream Empty, Header, Title, Description, Media and Content. The existing `src/components/ui/empty.tsx` is consumed in every entry; those capabilities are not reimplemented. Free8's member-invitation slot pattern and free Card+Empty patterns guide7/9/10. The original layout-specific copy/alignment/actions extend those slots.
- **IconStack:** existing actual official `src/components/reui/icon-stack.tsx` supplies the complete layered SVG geometry, fading strokes, shadow and transformed content overlay for8/9/10. Target, Tag, UserPlus and LayoutTemplate are child Lucide glyphs. No equivalent layered illustration is redrawn in this batch.
- **Clipboard:** `npx shadcn@latest view @reui/use-copy-to-clipboard @reui/c-collapsible-7` returned the official free Hook and a real consumer. The Hook has no dependencies beyond React and was absent from installed `src/hooks`. Its actual source is reused in owned `team-setup/free/use-copy-to-clipboard.ts`, with provenance and MIT notice; only repository formatting is applied. Both invite layouts consume `isCopied` and `copyToClipboard`, including upstream2000ms reset behavior. Source: <https://reui.io/r/radix-nova/use-copy-to-clipboard.json>. Example: <https://reui.io/components/collapsible/c-collapsible-7>.
- **File Upload:** existing official `src/hooks/use-file-upload.ts` was previously byte-compared with registry source. Blueprint import consumes `getInputProps`, `openFileDialog`, `onFilesAdded`, upstream type/size validation and `clearFiles`. No custom file-picker or validation substitute is created.
- **Other existing source:** actual free Badge and Alert render local statuses and errors. Upstream Item, Card, Tabs, Input, Textarea, Avatar, Dialog and Select are the same primitives actually consumed by the audited free REUI examples.
- **License:** existing upstream `src/components/reui/REUI-LICENSE.txt` remains in complete source exports. There are no new brand assets, portraits or paid images.

## Confirmed missing domain capabilities

The free Empty examples contain presentation/action slots; they do not implement team directories, invitation delivery, workspace permissions, project configuration persistence, check-in conversations or a reusable blueprint business schema. Custom code is restricted to these local fixture/data transitions and page arrangement. Blueprint JSON validates name, description and tasks because the free File Upload Hook does not parse content. It does not duplicate file selection or file-size/type checks.

## Functional limits and fidelity differences

Invites are marked local drafts and send no emails. The copied `.example` URL grants no access. The actual upstream clipboard Hook reports successful writes and resets its state; a browser with no Clipboard API receives a manual selectable URL dialog. Permission rejection retains the upstream behavior (logs failure, does not falsely mark copied); manual URL selection is also available in the invite dialog.

Directory sync uses three clearly identified fixtures. Milestone/brief/check-in setup remains in local state; it does not start a remote call or workflow. Project states/labels persist only while the preview is mounted. Blueprints are local objects, not templates saved to an account. JSON import is limited to64KB and20tasks of120characters; these are deliberate domain preview limits.

Mobile blueprint media/content stacks instead of forcing a horizontal desktop row outside390px. Other initial layouts retain the observed widths, alignment, buttons, copy and media hierarchy.

# Checkout / Shopping Cart individual preview audit

## Constraints and provenance

This is a separate ledger for the new Checkout7 / Cart7 batch. The earlier 22-product ledger and consumer files remain frozen for the root release. No Pro source, paid registries, or premium photographs were requested or retrieved. Research used rendered public preview pages and their interactive controls. All checkout, authentication and payment actions are local simulations.

Actual official free reuse, rather than parallel substitutes:

- **REUI Stepper**: `src/components/reui/stepper.tsx`, retrieved with `npx shadcn@latest view @reui/stepper`; official registry https://reui.io/r/radix-nova/stepper.json. The registry source was preserved with provenance; its controlled selection, actual trigger registration, arrow/Home/End focus and Enter activation, disabled states, indicator and separator styling drive the navigation. The source gained an `asChild` extension through the shared coordinator; this batch does not change it.
- **Free c-stepper-1 pattern**: actual `Stepper > StepperNav > StepperItem > StepperTrigger > StepperIndicator`, sibling `StepperSeparator` composition, from `npx shadcn@latest view @reui/c-stepper-1`. Domain forms use controlled step selection, native field validation and explicit checkout progression; only completed steps may be revisited.
- **Breadcrumb / c-breadcrumb-1**: stock Radix Nova shadcn Breadcrumb source obtained via `npx shadcn@latest view breadcrumb`, absent before addition. Only the registry IconPlaceholder calls were mechanically resolved to Lucide. The official free REUI `c-breadcrumb-1` composition supplies navigation/list/item/link/separator/current-page roles. Links perform local bag/store feedback in this demo.
- **REUI Frame / FramePanel / FrameHeader / FrameFooter**: actual inherited panel radius/background/spacing implementation is used for checkout5 summary, checkout3 credit purchase and checkout6 order summary. Existing sources are consumed, unchanged.
- **REUI Badge, Alert, IconTile**: actual sources provide semantic statuses/discount badges, order confirmations/feedback, and provider icon framing. Existing sources are consumed, unchanged.
- Stock shadcn primitives fill capabilities not replaced by a separate free REUI component: Field/Input, InputGroup, Checkbox, RadioGroup, Select, Switch, Dialog, Collapsible, Button and Separator. No carousel ability is hand-built; carousel dependency/source ownership remains with root.
- **Custom domain gap**: REUI free primitives do not supply these complete order/address/account/provider package models. Original local state composes them for pricing, validation, saved addresses, payment choice, account intent, promotion eligibility and simulated order submission. No payment processor, OAuth service, tax service or backend is connected.

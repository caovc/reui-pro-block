# Template Source file-switch identity

This consumer-only change keeps the existing free ReUI CodeBlock root keyed by template identity instead of template plus filename. Selecting another file therefore updates its controlled code/language/label without intentionally unmounting the file Select and entire toolbar. Only CodeBlockCopyButton is keyed by filename, so its Copied/error feedback resets for the new document. The block CodeViewer already uses this stable-root, file-keyed Copy pattern.

The actual native Select/Dialog, free CodeBlock renderer, full source DOM, syntax highlighter, line numbers, Wrap, Copy and download implementations remain in use. The existing focus handoff remains; its comment now describes the live trigger rather than a deliberately detached trigger. No file options, ordering, source collector, ZIP, foundation/style selection, original asset or MIT/OFL contract is changed.

## Existing state and stale-result contracts

The selected filename remains controlled by templateId plus filename state, with the existing membership/default-file fallback. The complete `files[filename]` string still feeds the actual CodeBlock and its Copy/download document context. Changing template identity still remounts the root.

The free CodeBlock already tags highlighter results with source and presentation spec, invalidates the previous request on dependency cleanup, and falls back to plain lines when the highlighted document does not match the current deferred source/spec. Its deferred render may briefly retain the previous document while preparing another; this change does not promise a synchronous new-file paint or alter that existing renderer contract. Exact selected-file DOM bytes, rapid switching and native focus still require rendered validation on the new candidate.

Wrap stays controlled by the existing parent state, so changing filenames retains the chosen wrapping preference. Keying only Copy resets acknowledgement/error state without resetting the native selector or Wrap. No new test, assertion, focus mock, timing delay or scheduler was added.

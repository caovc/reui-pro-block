# Strata public integration: review in progress

The public parent composes the observed product and authentication routes from
the independently implemented Strata modules. Workspace metadata, pins and page
models survive local navigation. Account shortcuts use the real Settings query,
saved profile details feed the account menu, theme controls update the global
theme, and Sign Out confirmation opens the observed independent sign-in page.
Authentication and workspace creation remain explicitly local demonstrations.

The implementation actually reuses the existing free ReUI Sidebar, Tree, Frame,
DataGrid, Filters, EventCalendar, Chart and CodeBlock compositions, along with
their real selected-foundation controls. It uses the original Bricklane mark,
local portraits and an independent CSS workspace illustration. There is no
premium source or reference media in the application or downloaded project.

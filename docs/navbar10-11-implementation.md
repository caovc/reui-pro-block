## Custom capability gaps

No free example supplies the complete API-console or DesignOps header. Header grid, mobile wrap rules, service/source fixture data and local response state are domain composition around the actual free implementations. The free request example has an uncontrolled path and inert Send; controlled state, input validation and a captured asynchronous fixture make its preview useful without claiming a backend. No real sync, API authentication, billing or account mutation is implemented.

The existing frozen theme hook updates the demo scene and account popup. Other portaled menus/dialogs inherit the preview's global theme, so full cross-portal theme parity is a known inherited limitation. Other differences awaiting original visual evidence include exact spacing, version text, provider/account rows and responsive breakpoints.

## Integration contract

- Add `DeveloperNavbarBlock` from `./navbar-variants/developer` to the application dispatcher and route only `9 <= block.index < 11` inside the navbar case, ahead of the existing fallback. All catalog indexes are zero-based.
- Map one-based source variants 10 → `navbar-variants/developer/api`, 11 → `navbar-variants/developer/design`, preserving the existing workspace fallback. Both leaves statically import their actual free adapters so recursive source and starter export resolve the same implementation.
- No edits to shared dispatcher/source files, package/lock, shared UI or earlier frozen leaves belong to the owned payload.

## Actual free-source reuse map

The free sources were inspected before implementation, not added as unused imports. Their original mechanics are executed by the previews.

- `first-run/free/dialog-surface.tsx` is the existing, unchanged official free `c-dialog-3 / c-dialog-6` header/body/footer composition. `first-run/support.tsx` supplies the real free Frame-based launcher. The upstream Radix Dialog still owns dismiss, close, title/description and focus mechanics.
- `workspace/free/status-picker.tsx`: actual [c-combobox-21](https://reui.io/r/radix-nova/c-combobox-21.json), retaining status glyphs and item choices.
- `workspace/free/priority-picker.tsx`: actual [c-combobox-22](https://reui.io/r/radix-nova/c-combobox-22.json), retaining the free priority bar SVG geometry and choices.
- `workspace/free/members-picker.tsx`: actual [c-combobox-24](https://reui.io/r/radix-nova/c-combobox-24.json), retaining the multiple-selection summaries, actual AvatarGroup and clear option. Controlled values, observed fixture names and original avatars replace source fixtures. A function-child list follows official free Combobox guidance and makes typing actually filter.
- `workspace/free/labels-picker.tsx`: actual [c-combobox-26](https://reui.io/r/radix-nova/c-combobox-26.json), retaining multi-label dots/summary and clear semantics; controlled values and function-child list are adapters.
- `workspace/free/cover-upload.tsx`: actual [c-file-upload-10](https://reui.io/r/radix-nova/c-file-upload-10.json), preserving official `useFileUpload` drag/drop, type/size validation, input props, image loading and clear state. Original demo art replaces source remote image. Fake network progress/random failure is removed because there is no upload backend. The callback supplies the actual File.
- `workspace/free/avatar-upload.tsx`: actual [c-file-upload-2](https://reui.io/r/radix-nova/c-file-upload-2.json), retaining official hook, preview and validation. Compact row and actual Change/Remove actions adapt it to the observed settings layout. No fabricated upload service.
- `src/components/ui/combobox.tsx`: actual official shadcn radix-nova CLI output, **BaseUI Combobox**, explicitly prescribed by REUI's free [Combobox documentation](https://reui.io/docs/radix/combobox). `npx shadcn@latest add combobox --yes` ran in a scratch copy to avoid overwriting four installed shared dependencies; only the new module was copied. Existing dependencies sufficed. Alias normalized to `@/lib/utils`, upstream API retained, provenance/MIT header added; runtime AST matches generated source after alias/format normalization. No Command/Popover substitute.
- `src/components/ui/kbd.tsx`: official shadcn CLI new-file output; dry run listed exactly one new file and existing cn utility. Installed after Root authorization, alias normalized, formatted. Actual InputGroup addon uses it. No package/lock change.
- Actual installed free `Frame`, `IconTile`, `Badge`, `Alert` are used in rendered launch/support/results. Official free docs specify upstream Item, Field, Dialog, InputGroup, Select, Tabs and Empty for these compositions; those installed primitives are consumed directly.

Every adapted free module retains its source URL and MIT attribution. Shared REUI license remains in downloaded projects. Data-URI art comes from the repository's original `demo-artwork.ts`; no paid or original-site media is distributed.

## Custom gaps and limits

The free library supplies inputs, layout and interaction mechanics, but no app-connection backend, invitation transport, project persistence, support mailbox, booking service or account settings service. Local state, validation and clearly labeled draft results fill those gaps. They are not represented as network collaboration, OAuth authorization or live billing.

The isolated production candidate patches only exact routing/source targets: catalog zero-based indices 5–9 use `WorkspaceDialogBlock`; source variants 6–10 map to `apps`, `support-hub`, `invites`, `project`, `settings`. Working shared dispatcher/source-targets are left for Root's narrow integration.

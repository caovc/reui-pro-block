# Review1/5/6: actual free carousel compositions

## Scope and original media

This independent milestone owns `review-data.ts`, `review-common.tsx`, `review-carousels.tsx`, `review-carousel-pages.tsx`, `tests/review-carousels.spec.ts` and this ledger. The remaining Review2/3/4 entries keep their existing dispatcher until a separate list/filter/summary milestone. Shared UI source, package/lock, source viewer and the working dispatcher are not changed by this child batch.

All six reviewers and all feedback paragraphs/quotes are fictional original demo content. Every avatar now uses the repository's independently authored `demoAvatar` SVG illustration from `src/lib/demo-artwork.ts`, rendered through the actual Avatar/AvatarImage/Fallback composition. The initially researched free-example photo replacements were removed before publication: all six JPG files and their imports were deleted, including the photo found to overlap a reference avatar. This change is applied to runtime source and download contents, not only a ZIP exclusion. New reviews also receive an original local illustration. No reference photos, upstream SVG media, premium source, logo or paid media are distributed by this milestone.

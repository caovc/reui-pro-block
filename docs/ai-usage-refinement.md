## Behavior and explicit limits

Planner uses graduated10M/100M/1B bands, selected add-on flat/unit charges and optional annual reduction. Slider keyboard operations update the real token value, quote and exported plan. Save is local state and a toast. Spend Map maintains931 in every dimension, sorts by the chosen metric, updates the dollar inspector, scrubs daily samples summing to the selected total, exports the visible leaf records and returns explicit canned local answers.

Edge Nodes preserves power caps, deployments and acceptance/update settings per node. Deploy/Unload changes the node's model list and illustrated memory state. Hardware parts support mouse and Enter/Space, the lid controls share state and the offline node disables deployment. Power telemetry is calculated from the chosen cap; it is not a live fleet. Local Models keeps applied and draft configs, recomputes weights/KV cache/per-GPU loads, blocks Apply on any over-capacity GPU, supports Fit/Discard/Apply, and copies/downloads the real draft JSON. Restart is an explicit local demonstration. The4GPU/48GB fixture and formulas are illustrative; rounding can differ0.1GB from the public preview.

Remaining fidelity differences: hosted card logos use Lucide marks; public portraits are omitted. Planner's cumulative curve is independently generated. Spend Map's fan paths are original responsive curves with simplified junctions; the public dial ticks, animated transitions and owner portraits differ. Edge/server diagrams intentionally use original simpler hardware construction with different proportions, fan/vent detail and materials. Node picker grouping, public exact fleet/catalog fixtures, model-specific precision availability and full server action menus are simplified. No pixel-identical or real-backend claim is made.

A coordinated shared Slider correction, authorized by root, adds only `aria-valuetext={props["aria-valuetext"]}` to Thumb so the Planner's nonlinear index is announced as tokens. Root/Thumb mechanics and API otherwise remain unchanged. Tests assert token Home reads1,000,000 tokens, while an ordinary local-model Slider without value text keeps that attribute absent.

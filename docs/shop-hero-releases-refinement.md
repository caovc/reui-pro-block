- **Existing `ShopImageCard` / official [`c-card-8`](https://reui.io/r/radix-nova/c-card-8.json)**: all three leaves directly consume the frozen helper. The official image positioning, zoom, fade and content composition remain actual reused code; no new gallery/image primitive is added.
- **Official [`c-tabs-9`](https://reui.io/r/radix-nova/c-tabs-9.json)**: the switcher retains the real value/onValueChange, TabsList, TabsTrigger and distinct TabsContent structure. No hand-built tab selection or keyboard mechanics replace it.
- **Official [`c-badge-22`](https://reui.io/r/radix-nova/c-badge-22.json)**: `release-status.tsx` retains the actual REUI Badge plus `ms-0.25 size-1.25 rounded-full! bg-[currentColor]` dot composition. Phase variants, image contrast and optional ping extend that real implementation. Official free source SHA-256: `eacbcdf76756fdf530b7ccad5c9e44a4ae42ff08098e86adbfdabee7322b18f3`.
- **Official [`c-dialog-1`](https://reui.io/r/radix-nova/c-dialog-1.json)**: `drop-reminder.tsx` retains the actual controlled Dialog, native form, FormData handling, FieldGroup/Field/Label/Input and footer/close structure; email data replaces profile fields. Existing FieldError and official Alert expose invalid/saved states. No duplicate modal/focus primitive is introduced.
- **Existing `CollectionBrowser` / `CollectionSaveProvider`**: edit, all three tab panels and all four quilt tiles reuse the exact frozen 4–5 catalog implementation, including actual c-item-2 rows, c-tabs-9 category controls, c-scroll-area-1 and c-toggle-10 saved state. No second catalog search, save or detail implementation is created.
- **Official Frame / Item / ScrollArea / Badge / Alert**: Archive composes the existing Frame/FramePanel source, c-item-2 media/content/actions anatomy and actual c-scroll-area-1 viewport for the price-cut rows and notice.

The public free registry was searched for discount/price-cut/reminder examples; it does not supply a sale calculator, collection dataset or reminder delivery store. Custom code is restricted to typed sample data, exact price arithmetic, phase metadata and local reminder state. The frozen catalog helper does not accept sale prices, so the small read-only Archive dialog adds only that missing domain presentation while consuming the same official primitives. No backend or external email delivery is added.

## Official free components used

The implementation was migrated after auditing the official free registry. Gantt consumes the actual nine-file implementation from [ReUI Gantt](https://reui.io/r/radix-nova/gantt.json): `Gantt`, `GanttView`, `GanttNav`, navigation/scale controls, split panes, timeline scrolling, drag/resize, resource reordering, event selection and dependency rendering. Files live in `src/components/reui/gantt/`. Compatibility edits are the local lucide `IconPlaceholder` adapter, Vite environment check, removal of an unused type, and project oxfmt formatting. Task forms, domain validation and fixtures are separate consumers of that engine. Read-only job/run/booking details compose the real ReUI Badge and the Sheet, Alert, Item, ScrollArea and Button dependencies used by official free examples, with metadata hydrated once from 55 publicly rendered detail entries; edits and duplicates retain instance values.

The free registry had no Flow/Canvas engine equivalent. Flow therefore uses the official third-party `@xyflow/react` v12 engine (`ReactFlow`, handles/edges, controlled viewport, native dragging/selection, `NodeToolbar`, `MiniMap`, `Background`, `fitView`). Node content actually composes the official free [Frame](https://reui.io/r/radix-nova/frame.json), `FramePanel` and [IconTile](https://reui.io/r/radix-nova/icon-tile.json) implementations. IconTile is shared and maintained by the AppShell owner. No local pan/zoom/drag engine remains. Layout and run replay are independent demo business logic.

## Practical limits

Runs and data edits are local demo state; there is no backend scheduler or persistence service. Brand glyphs are independent small SVG/lucide approximations rather than assets from the Pro source. Free React Flow provides the interaction engine; the graph fixtures, correlation paths and explicit layout routine are locally authored. Small remaining visual differences include independent brand/control glyph shapes, some inspector field spacing and fine badge outlines. No claim of pixel identity or backend equivalence is made.

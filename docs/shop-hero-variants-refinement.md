# Shop Hero refinement

Scope: eight public Shop Hero catalog entries, delivered as small independent batches. This ledger records rendered public observations separately from metadata and locally added behavior. No Pro implementation or upstream preview media was retrieved.

## Actual official free reuse

- REUI [`c-item-2`](https://reui.io/r/radix-nova/c-item-2.json): actual `Item` / `ItemMedia` / `ItemContent` / `ItemTitle` / `ItemDescription` / `ItemActions` composition, adapted for product labels, prices, cart rows and curator content. The project already contains the official stock Item source; no duplicate primitive is added.
- REUI [`badge`](https://reui.io/r/radix-nova/badge.json): directly consumes `@/components/reui/badge`; actual `success`, `success-light` and `destructive` variants retain the original status styling.
- REUI [`number-field`](https://reui.io/r/radix-nova/number-field.json): directly consumes the existing Base UI implementation for bounded quantities, editable numeric values and native disabled decrement. Its native input is a text box with numeric input behavior, not a browser spinbutton.
- REUI [`frame`](https://reui.io/r/radix-nova/frame.json) and [`alert`](https://reui.io/r/radix-nova/alert.json): actual shared source imports provide stacked cart panels and state announcements.
- REUI [`c-card-8`](https://reui.io/r/radix-nova/c-card-8.json): read the official source before implementation. `image-card.tsx` retains the actual positioned image, hover zoom, gradient and content composition, with local media, responsive dimensions and domain content. It is consumed by the Bento campaign and Countdown Deal banner; it is not claimed as consumed by Live Cart Hero. The official source SHA-256 is `572d0b6b8aad4d5203c684e306f97772409f8bbadb4f2eef9af02cb7bd76eea0`.
- Also read official free `c-card-9`, `c-card-10`, `c-tabs-1`, `c-tabs-9` and `c-sonner-16`. The latter is a static session-expiration notice, not a ticking countdown. No free countdown primitive was found in the public free registry listing. No clipboard hook is misused for cart feedback.

- REUI [`rating`](https://reui.io/r/radix-nova/rating.json): the Countdown Deal social-proof row consumes the existing official `Rating`; no duplicate star rendering is introduced.
- The Countdown Deal offer reuses the already verified `CouponCopyButton` from `coupon-variants/copy.tsx`, which consumes the existing official `use-copy-to-clipboard` hook under `application/empty-variants/team-setup/free`. This is the actual `c-button-41` feedback composition and native Popover failure guidance, not a duplicate hook.

Shared official sources are consumed unchanged. Existing MIT notices and starter attribution remain intact. Collection dialogs and cart arithmetic are local commerce behavior; the free library supplies their underlying controls but does not supply a storefront cart store.

## Original media

`shop-hero-variants/artwork.ts` contains independently drawn bag/daypack/tote still lifes composed of basic paths, rectangles, linear gradients and shadows. `svgImage` serializes these original drawings; `demoAvatar` supplies the fictional curator. No external image request, upstream logo, extracted SVG, premium photo or screenshot is used. These illustrations intentionally differ from reference photographs and are included transitively in the source download.

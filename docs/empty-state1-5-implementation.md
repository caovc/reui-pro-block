## Source and formatting

Owned implementation modules are readable, multiple-line TypeScript and scoped CSS. The two upstream illustration bodies differ only in export/provenance wrapper and repository formatting. Their public registry references are <https://reui.io/r/radix-nova/c-empty-15.json> and <https://reui.io/r/radix-nova/c-empty-16.json>. Existing shared source is consumed without overwrite. Application dispatcher receives only one import and an Empty1–5 conditional;6–14 remain routed to their prior implementation until their next independent batch. Shared source-target mapping is coordinated with the source/formatting owner.

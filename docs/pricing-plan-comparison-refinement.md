# Pricing 2 — Plan Comparison

## Observed public reference

Reviewed on 2026-10-26: [catalog and public brief](https://reui.io/blocks/marketing/pricing/pricing-2), then the actual [public rendered preview](https://reui.io/preview/base/pricing-2). Headless Playwright Chromium was explicitly requested so that the shared browser remained untouched. Only rendered DOM, screenshots, computed styles and public interactions were inspected; no premium source was obtained.

The previous generic index-1 implementation had a billing switch, invented plan values and purchase dialogs, and a bounded scrolling table. This dedicated page replaces that behavior with the observed four-plan usage matrix: Free $0, Pro $28, Team $40+, Unlimited $750+. These are monthly amounts billed yearly. The Team starting price covers two seats; the comparison prints the observed $20 per seat rate. There is no billing-period control or seat stepper on this page.

All 26 dotted feature labels were actually clicked on the reference. Each opens its own explanatory Popover; subgroup headings are plain text. Four banded sections contain Collection, Retention, Reporting, and Team and Access. Volume controls, Retention by record, and Billing are indented subgroups with no internal horizontal rules. Metered allowances print above their rates. Boolean cells retain accessible Included / Not included text alongside Lucide check/minus marks.

At 390px the native single ToggleGroup initially selects Pro. Free, Pro, Team and Unlimited each display their own complete column, prices and CTA; pressing the selected option does not deselect it. The four captured mobile document heights are 1879, 1911, 1927 and 1879px. All four reference CTAs have `href="#"`; clicking each returns the page to the top after its native smooth scroll settles and opens no dialog. The local anchors prevent the default hash navigation, retain the gallery route and scroll to the top without inventing payment or confirmation flows.

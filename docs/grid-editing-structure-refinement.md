## Current architecture: official free ReUI and TanStack Table v9

The earlier shadcn/native-table reconstruction has been replaced. Every entry above now owns a real `useTable({ features: dataGridFeatures, columns, data, getRowId, ... })` instance and `ColumnDef<DataGridFeatures, T>` definitions. `grid-structure-model.tsx` only composes the official renderers; it does not walk arrays to generate table rows or substitute a hand-written table.

| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Labels, Sprint Backlog, Routing Rules | `DataGridTableDndRows` / `DataGridTableDndRowHandle`; stable row ids and table row model; dnd-kit end events write the data order. The expansion grids mount `DataGridPagination` inside their shared DataGrid provider; pagination controls call the same real table model. Unused legacy table, sort and pagination helpers have been removed.

Other free ReUI primitives are used substantively: `Badge` for domain status/priority labels; `Frame`/`FramePanel`/`FrameHeader`/`FrameTitle`/`FrameDescription` for grid chrome; `ColorPicker` for label color controls; `NumberField` for budgets, seats and spreadsheet numbers; `Rating` for release checklist stars; official `Filters` through the coordinator's `FilterBar` adapter for runbook/task/virtual-feed query builders. Shared Drive remains a tree _table_ through `getSubRows`, so a separate tree-navigation widget is not substituted for the grid.

## Visual comparison and corrections

Compared native-size public preview and local screenshots with `view_image`, including container width, actual columns, table density, typography, badges, toolbar hierarchy, nested rows, checklist cards, meters and narrow-screen scrolling. Wide previews use a 1216px maximum width; Labels uses an 832px list. Main table text reads at 14px and secondary data at 12px. Official Frame panels use their public zero-padding variables for full-bleed tables. Column widths were recalibrated so Runbook's Points column remains visible on desktop and Intake does not unnecessarily scroll horizontally.

Long tables scroll inside the official grid viewport. Search occupies a usable row on mobile instead of being squeezed by action buttons. Drive rollups, Runbook completion totals, Reorder approved totals and shipment KPIs derive from their data. In-memory seed populations retain the reference scale: 10,000 payments, 8,000 shipments, 285 stock lines, and 60 tasks.

## Scope and remaining differences

This is an independent reconstruction using official free primitives, not licensed Pro source. Long offscreen feeds use deterministic local fixtures; data changes stay in memory. Payment brand marks remain simplified indicators. Custom spreadsheet columns currently support Text, Number and Date. Exact server integrations, every alternative ReUI style preset and every offscreen seeded record are outside this pass. Native range selection, clipboard, column/row dragging, resizing, sorting, tree expansion and virtualization are no longer simulated by custom table code.

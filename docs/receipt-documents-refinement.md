## Confirmed custom domain gaps

The free UI library supplies presentation primitives, not order-data calculation, PDF serialization, MIME email draft export or support-request storage. Original receipt-data.ts supplies those missing domain capabilities without dependencies/network requests. The PDF contains this local order data, valid object offsets/xref/trailer and a one-page A4 page. Email produces a usable .eml draft and explicitly does not claim to send it. Support produces a text request file and explicitly stays local. No external messages, payment or shipment are created.

All new TS/TSX/CSS/test files were formatted with the project's installed oxfmt before handoff. Shared Item/package/lock/source-viewer/config files and the frozen ProductCarousel release were not modified. The dispatcher is deliberately untouched; integration is limited to importing ReceiptDocuments and routing receipt indices0–2 to it while keeping indices3–5 on the existing implementation until the next independent batch.

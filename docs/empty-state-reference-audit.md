## Actual free source audit

- <https://reui.io/components/empty> installs upstream shadcn `empty`; all20 free `@reui/c-empty-N` registry examples were read via official shadcn `view`. The returned source imports the upstream Empty/Header/Title/Description/Media/Content slots. The existing `src/components/ui/empty.tsx` is therefore consumed directly; no extra renamed wrapper claims a distinct free component.
- `c-empty-15` and16 contain reusable helper implementations. The helper bodies are copied verbatim, then formatted with repository oxfmt, into scoped `empty-variants/free/stacked-cards.tsx` and `search-cards.tsx` with upstream MIT provenance. The project retains the official license at `src/components/reui/REUI-LICENSE.txt`.
- `c-empty-1` composes Empty/Header/Title/Description/Content and dual Button actions. `c-empty-5/8` compose Card with Empty. Those actual slot topologies are preserved; page-specific copy and secondary guide rows extend them.
- <https://reui.io/components/file-upload>: official `@reui/use-file-upload` and `c-file-upload-1` source were read. Existing `src/hooks/use-file-upload.ts` was compared with returned registry source and matches byte-for-byte after trimming. It supplies actual selection, file metadata, validation and reset. CSV parsing is missing from the free hook, so only that domain function is added locally.
- No shared component, dependency, lockfile, global stylesheet, or package script changed in this Empty batch.

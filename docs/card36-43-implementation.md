## Actual free source and example audit

The installed actual sources for Frame, IconTile, Badge and Alert were read before composition. The actual free Frame3 and IconTile17 registry examples informed the panel and raised-color tile patterns. Existing upstream Avatar/AvatarBadge/AvatarGroup, ScrollArea/ScrollBar, Item and AspectRatio sources were then read; REUI's public [Avatar](https://reui.io/components/avatar), [Scroll Area](https://reui.io/components/scroll-area), [Item](https://reui.io/components/item) and [Chart](https://reui.io/components/chart) pages explicitly point to these upstream primitives. No new package, shared file overwrite or registry install was needed.

For the independent portfolio UI miniature, actual free `@reui/c-chart-1` source was read via `shadcn view`: its real ChartContainer→Recharts BarChart→Bar composition is consumed with sample data and animations off. Handwritten bar-shaped divs were replaced during this audit with the actual chart primitive rather than reimplementing an available capability. The miniature is decorative and aria-hidden, without pretending it is original photo media or a live analytics dashboard.

## Actual official free reuse and domain gaps

- Existing **Item** source is read-only. The actual free [c-item-4](https://reui.io/components/item/c-item-4) clickable navigation structure and [c-item-5](https://reui.io/components/item/c-item-5) ItemGroup/Media/Content/Actions structure were inspected before composition; there is no generic substitute list/tile implementation.
- Existing official **Rating** supplies editable star behavior and read-only saved review rendering. **NumberField** supplies real parsing, clamp, keyboard and +/- controls in both return and reorder forms. Return maximums use the original purchased quantity; reorder maximum20 is a local shop-demo rule. No parallel custom rating or quantity stepper was built.
- Existing official **Frame/FramePanel/FrameFooter**, **Badge**, **Alert** and previously added actual **Timeline/c-timeline-1** are consumed unchanged. MIT attribution remains in the project and source ZIP.
- Stock shadcn Dialog/Checkbox/Select/Input/Textarea/DropdownMenu/Button/Separator provide the remaining existing free controls. DropdownMenu's original menu selection/focus behavior is preserved.
- Free UI primitives do not supply this order's review records, cart state, prorated return/refund estimate or support files. `ReceiptAftercare` provides only that domain orchestration. Refund estimate distributes the original post-discount/tax merchandise amount proportionately and excludes shipping; it is labelled an estimate and never initiates a refund. Local return/support requests download actual text files; original order history remains unchanged.
- All added source/test files are readable multiline and were formatted/check-tested through the repository's **oxfmt** scripts after the tooling migration. **oxlint** and strict scoped TypeScript checks pass. No package/lock/config/shared source changes or Git operations.

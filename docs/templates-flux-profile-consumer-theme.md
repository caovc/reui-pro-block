## Known remaining structure gaps

The existing avatar adapter has no action-icon slot: its actual Change/Remove Buttons are plain text. The reference has native upload/X icons. This proposal does not insert pseudo icons, extract SVG or force empty icon space; action widths therefore retain the real content difference. The Profile Public Details title has no existing Info/Tooltip slot. Its absent28px Info trigger can leave an8.75px phone field-stack difference around that title; the proposal does not add a fake spacer/button or claim that missing interaction is restored. Both require separate review of a minimal real Lucide/free Tooltip opt-in composition if included. Original/local avatar and Bricklane example values remain intentional substitutes, not visual defects.

The first theme appended only `src/templates/workflow/flux-settings.css`, preserving its earlier prefix. The narrow follow-up adds one opt-in nested Field gap rule and removes Select from the transparent-default-border selector; it does not change that earlier pre-theme prefix. Every new rule is scoped to `.wf-flux-profile-dialog`; default AccountSettingsDialog does not receive that class. Eight relevant Pro/free source files are byte-identical to the first-main input and are absent from this payload, as recorded in `proof/default-pro-byte-guard.json`. No new shared API, SourceTargets, package or asset is introduced. CSS formatting/parsing is checked; oxlint is not a CSS linter and there are no changed TS/JS files to lint.

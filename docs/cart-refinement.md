# Shopping Cart7 refinement milestone

## Official free-first composition

This batch replaces seven generic cart-family layouts with individually audited pages/overlays. It changes only new `cart-refined.tsx`, `cart-pages.tsx`, `cart-overlays.tsx`, `cart-shared.tsx`, its test and this ledger. The accepted22-product consumers/dispatcher/ledger and the Checkout7 ready batch remain unchanged.

All quantities use the **actual official REUI NumberField** source already installed by the shared coordinator. `NumberField`, `NumberFieldGroup`, `NumberFieldDecrement`, `NumberFieldInput` and `NumberFieldIncrement` preserve its BaseUI input parsing, ArrowUp/ArrowDown, maximum clamping, disabled limits and focus behavior. At quantity1, overlays supply a trash icon through the component's original children API and permit value0 to remove the item. There is no parallel custom quantity stepper.

Actual **REUI Frame/FramePanel/Header/Footer**, **Badge**, and **Alert** sources supply framed delivery/featured-item panels, semantic labels, and local checkout confirmation. Sources are consumed unchanged. Breadcrumb follows the verified free c-breadcrumb-1 composition and official stock component added in Checkout7. Shadcn Popover, Sheet, ScrollArea, Table, RadioGroup, Dialog, Progress, InputGroup, Button and Label provide the remaining free capabilities. Cart6 uses Popover to keep quantity input usable without menu-item auto-dismiss; Cart7 uses Sheet's real focus trap, modal overlay, keyboard dismissal and close/reopen state. No carousel is recreated or dependency installed.

Free REUI does not include these complete product-order/fulfillment/promotion models. Original domain state supplies line/subtotals, save-for-later, fulfillment, discount eligibility, delivery destination and local payment review. Checkout buttons open an explicit local order review showing total and selected payment; no real payment/OAuth/backend request occurs.

## Official free component composition

The 13 entries now render through the official free ReUI Data Grid registry files in `src/components/reui/data-grid/`, backed by `@tanstack/react-table` v9.3.1. This replaces the earlier handwritten table implementation. The registry components are not modified by these blocks.

Every entry imports `useGridTable`/`NativeGrid`/`NativeTable` from `grid-base-engine.tsx`. `useGridTable` converts its domain columns into real `ColumnDef<DataGridFeatures, T>[]`, and calls `useTable({ features: dataGridFeatures, data, columns, ... })` with the complete raw dataset. `state.globalFilter` and `globalFilterFn` evaluate domain search, facets, and rule queries inside the native filtered row model. Native sorting, pagination, row selection, column visibility/order/sizing/pinning, and row pinning use table state and the registered row models. There is no manual slice, manual sort, prefiltered dataset, or `manualPagination` workaround in these 13 entries.

All 13 containers compose official `Frame`, `FrameHeader`, `FrameTitle`, `FrameDescription`, and `FramePanel`. Status chips use official `Badge`. Custom progress rings, sparklines, rates, and scope switches are domain cell presentations for which a free grid provides no business-specific renderer.

## Practical limits

This is a substantial fidelity pass, not a claim of pixel-identical reproduction of every official state. Generic create dialogs accept a name rather than a full production domain form; some secondary seeded records and inactive-tab scope labels are independently authored. Integration badges are independent typographic drawings rather than copies of vendor logos. Filters operate on local demo data through the native global filter row model; nested boolean filter queries use the shared query matcher. Avatar and badge artwork is authored locally in `src/lib/demo-artwork.ts` and `grid-base-assets.ts`; the earlier reference portrait payloads and external photo identifiers have been removed.

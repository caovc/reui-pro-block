# Card 16–29: public-reference audit and free-component implementation

Audit date: 2026-10-22–23. Scope is exactly `card-16` through `card-29`. Card 1–15 modules/helpers/CSS and Card 30–43/EmptyBlock behavior were preserved. Root coordinates the verified milestone's commit/push; this agent performs no Git writes.

## Reference and source method

Each entry was opened individually on its public detail page, then its actual “Open preview in new tab” link was followed to `https://reui.io/preview/radix/card-N` and inspected at 1440×900. Public buttons and menus were exercised where present. Public `.md` briefs were read for 16–23 and 25–29; Card 24's brief request repeatedly failed, so its rendered detail/preview supplied the evidence. No Pro registry payload or paid media was fetched. Public fixture quirks (BTS/USD, Binance logo beside CRM/Resend copy) are retained intentionally.

Before implementation, the actual installed free REUI sources and registry examples were audited. Actual source of `@reui/c-frame-3` (stacked direct sibling panels) and `@reui/c-icon-tile-17` (elevated tile with brand color override) was read with `shadcn view`. These patterns are consumed in the new modules, rather than recreating a free Frame/IconTile shell.

## Validation and evidence

The flow under test is: each dedicated Card 16–29 route renders → its meaningful local control is exercised → expected visible state is checked. Browser plugin/`browser` skill was not available in this session; public-reference UI used the provided CUA Edge tab, and the owned local app used the project's Playwright workflow.

- `npx tsc -p src/blocks/application/card-variants/extended/tsconfig.audit.json --pretty false`: scoped module/dependency/router TypeScript passed (temporary audit config removed before handoff).
- `npx oxlint src/blocks/application/card-variants/extended`: passed.
- `npx playwright test tests/card-extended.spec.ts --workers=2`: 10 passed. The two matrix tests cover all 14 routes at 1440×900 and 390×900, check nonblank variant identity, actual Frame slots, no framework overlay, no browser errors and no horizontal document overflow.
- Eight behavior tests check integration edit/paused badge/guide; Follow/NumberField step and local sell total; distinct help articles; clipboard project sharing; real AspectRatio pair/CTA; retained monitor config/services; retained role application draft; static KPI figures and four decorative area SVGs.
- 28 screenshots captured outside the repo at `/tmp/reui-card-extended-audit/card-N-{1440,390}.png`. Reviewed desktop and narrow layouts for typography, clipped logos, wrapping and seam structure. Mobile card18's long URL overflow was found and corrected. Final screenshots refreshed after that correction.

Relevant global `tsc -b` run initially reported only separate coordinator files (`data/grid.tsx` Status props and `templates/workflow/mesh.tsx` unused Activity) after this batch's unused imports were removed. Those files were not modified here. Parent release must run its isolated integration build with the current accepted shared dependency graph.

Known scope limits: local state lasts for the mounted preview, not across browser reloads. Clipboard requires browser permission/secure context. Network exchange, job submission, backend monitoring and real analytics are intentionally absent. Pixel-exact type metrics, original photos, and all REUI theme variants have not been claimed or validated. Source code viewer recursively resolves explicit imports and local asset references for these modules; brand/media attribution is in `assets/card-extended/ATTRIBUTION.md`.

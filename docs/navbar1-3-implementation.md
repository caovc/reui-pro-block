## Implementation and integration

New source stays under `src/blocks/application/navbar-variants/first-run/`; no existing business source, shared UI, router, source-targets or package is edited. Root integrates two narrow changes:

1. Application router imports `RefinedNavbarBlock` from `./navbar-variants/first-run`, and for category `navbar` uses it for zero-based `block.index < 3`; all later IDs keep `NavBlock`.
2. Source targets for1-based variants<=3 prioritize `navbar-variants/first-run/project`, `presence`, `platform`, respectively, with existing `workspace` fallback. The actual module dependencies recursively include adapters/data/CSS.

These exact hooks were applied only to the isolated production candidate for testing. Bricklane's existing original mark and local generated avatars are consumed; no new external media or logos. Existing MIT/OFL notices remain in actual downloads.

The current catalog has **13** exact entries, `ai-chat-1` through `ai-chat-13`, not nine. All thirteen official public descriptive `.md` pages were individually read on 2026-10-23. They are behavior/dependency evidence, not rendered visual evidence. Browser commands currently time out and the human is active in Edge; no focus was taken to claim a visual pass.

All other twelve used `StandardChatBlock` in shared `ai.tsx`: a synchronous canned string was appended immediately, one composer/transcript was reused, and `block.index` changed headings and selected controls. This batch does not edit that shared file.

## Authorized new upstream Questionnaire

The REUI [Questionnaire docs](https://reui.io/components/questionnaire.md) delegate to [upstream Radix Questionnaire](https://ui.shadcn.com/docs/components/radix/questionnaire.md). The official dry-run reported one new `ui/questionnaire.tsx`, a Button overwrite, and `cn`/`@shadcn/react`. Both dependencies already exist; resolving `@shadcn/react/questionnaire` and `cn` succeeded.

With explicit coordinator authorization, `npx shadcn@latest add questionnaire --yes --overwrite` ran in an isolated scratch project. **Only the new Questionnaire file is copied**; no existing Button, dependency, package or lockfile is overwritten. Its wrappers consume the existing exported Button type and `buttonVariants({size,variant})`, whose required values/API are present. Scoped TypeScript and the actual required-choice, letter shortcut, next/submit, FormData and result-focus tests passed with the existing Button API.

Installed original source SHA-256: `55f270a3ff5206462c33717bab642ecfa2863a5d0c2f7e6adaea7d8f10350961`. The implementation is unchanged apart from formatting and the provenance/MIT header. No fake hand-built questionnaire replaces an available free implementation.

## Custom gaps and honesty requirements

Free examples provide the actual composer, attachments, message surfaces, stream behavior, transcript scrolling, reply actions, code rendering and guided questions. They do not supply the complete Pro application's thread store, pinned/recent history semantics, Insert/Undo document state, starter context binding, effort/model/context metadata or plan-generation controller. New local state adds only those application behaviors. There is no AI backend, OAuth, microphone capture or real document persistence; independent original fixtures and Lucide/initials replace reference media and marks.

Public rendered desktop/mobile for 1–3 remains **pending**. Working controls, strict builds and green tests will be labeled local functional evidence until public pixels/interactions can actually be inspected. No inherited Activity or Branching evidence is used to claim another entry's fidelity. Frozen Activity/Trace and shared ai.tsx/router/source-targets/package/UI remain protected; the only shared addition is the separately authorized NEW Questionnaire.

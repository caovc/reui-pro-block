Before implementation, the existing official `src/components/reui/frame.tsx`, `rating.tsx` and `alert.tsx` sources and the prior auth compositions were reviewed. There is no handwritten star-fill engine, framed-card substitute, or replacement input implementation. The free library does not supply these complete split-screen authentication layouts, grain/grid artwork, or customer identity system; the layout CSS is the consumer composition around the actual free primitives.

The demo uses the original Bricklane brand, locally drawn `demoAvatar` artwork and independently authored typographic customer badges through `integrationArtwork`. Fictional customer names and independently written quotes replace the reference endorsements and logos. These identity and artwork differences are intentional. OAuth, sign-in, signup and reset actions display local demo outcomes without an authentication service; they do not send mail or authenticate accounts.

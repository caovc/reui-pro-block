## Mobile layout correction

The public detail pages were checked through native Edge on2026-10-23 using their Mobile width controls. Auth9 and Auth12 keep the review panel below the form; scrolling Auth9's actual iframe confirmed its rating, quote, avatar and animated logo grid remain rendered. Auth13 keeps a tall framed image before the form. Auth14 hides its artwork panel. Earlier local prototypes incorrectly hid all four panels; the final CSS and regression assertions now preserve these distinct compositions.

Auth9/12 use six independently written stories and18 actual IconTile instances, with groups fading through consumer CSS. The free registry search and IconTile API expose no matching18-tile choreography, so only positioning/fading is custom; tile rendering and testimonial playback remain the actual free implementations. Reduced motion freezes decorative animation and disables autoplay. The exact logo designs, quote text and timings differ deliberately.

All actions are local demonstrations. Preparing an invitation,magic link,SSO choice,backup-code result or passkey selection does not send mail,verify an account,register a credential or create a session. Provider buttons retain the existing local preview feedback.

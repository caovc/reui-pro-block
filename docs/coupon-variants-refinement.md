# Coupon 1–6: public-reference refinement and actual free reuse

## Scope and evidence method

This independent implementation uses official free REUI sources already installed in the project. No Pro implementation was retrieved. Eight new modules live under `src/blocks/commerce/coupon-variants`; existing promotions, shared UI, package files, routing and source-target mappings remain untouched for Root's coordinated release.

All six public defaults were captured and individually inspected at1280×1100 and390×844. Public clipboard values, all six category filters and both dismiss/restore states were also inspected. These initial records used a separate headless research browser before the coordinator required subsequent public UI actions to use CUA. After that instruction, all further public actions used CUA only. CUA browser-tab binding timed out twice; its native Edge App API worked. In the dedicated Coupon audit tab it reconfirmed Coupon2's Seasonal filter, `1 of6` count and the accessible copy-success label `Code SUMMER25 copied`. A subsequent Coupon1 navigation stalled and was cancelled; it is not claimed as an additional CUA verification. Local production and starter tests continue to use headless Playwright.

## Confirmed custom gaps and media

Free REUI provides no coupon campaign data store, product eligibility evaluator or live checkout redemption backend. The new data and sample-shop arithmetic fill only these local domain gaps, using actual free NumberField/Item/Alert mechanics. Sample dates are preserved reference fixtures and identified as such in the terms dialog. Reloading resets quantities; no payment or remote order is made.

All six inspected designs contain text promo codes, not QR codes or barcodes. Registry search found a QR-related accordion example, but there was no corresponding need in these references, so no QR/barcode implementation was invented.

`artwork.ts` contains two original still-life illustrations made from basic geometric shapes through the existing `svgImage` helper. Shop sample images reuse the project's frozen original `wishlist-artwork.ts` drawings. No upstream photo, product logo or extracted SVG is included. The new modules have no ReUI/KeenThemes visual brand marks; official free-source attribution remains in comments and licensing records.

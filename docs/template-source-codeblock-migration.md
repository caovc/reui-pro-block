# Template source dialog: actual free CodeBlock migration

This candidate replaces the template source dialog's handwritten `<pre>` and clipboard handler with the installed official free ReUI `CodeBlock`, `CodeBlockHeader`, `CodeBlockContent`, `CodeBlockCopyButton`, `CodeBlockDownloadButton` and `CodeBlockWrapToggle`. The existing native Select, Dialog and project-download operation remain in use. No premium source, original preview assets or ReUI brand graphics are added.

## Exact text and line endings

The free code renderer uses block rows rather than newline text nodes. Its original `textContent` therefore concatenates line contents, while the template source contract requires the actual code element's text to equal the selected file. The local adaptation adds two optional `CodeBlockContent` props:

- `codeClassName` applies to the actual `<code>` element, excluding header and action labels.
- `preserveLineBreaks`, default false, restores the source's original LF, CRLF or CR at the end of each rendered row. Rows with an ending do not also render an empty `<br>`, preventing double-height blank lines. The deferred source supplied to the surface matches the source used to render its tokens. Existing consumers retain their previous defaults.

This is an adaptation of the actual free renderer, with its existing tokenization, line numbers, native controls and MIT notice retained. There is no hidden raw `<pre>` or duplicate source element. Template source remains keyed by template and filename so a file selection cannot display the previous file's deferred contents or previous copy feedback. Wrapping remains controlled outside that key and survives file changes.

## User behavior

The selected implementation can be highlighted, copied, wrapped and saved as a single UTF-8 file. Download project retains the existing complete template export. The native Dialog remembers the source trigger and returns focus to it when closed. Because the keyed code block replaces the file trigger, native Select's public `onCloseAutoFocus` returns focus to the current trigger after selection, guarded against a closed dialog. The code viewport owns its real scrolling, and a wrapping header accommodates phone widths.

No source-engine, bundle, package manifest, global export or source-target routing changes are part of this candidate. The implementation targets and source ordering remain the existing ones. The five `tests/templates-source-round3.spec.ts` contracts remain separately owned, including exact `.template-source-code.textContent()`, clipboard and real ZIP assertions; this migration does not edit or weaken them.

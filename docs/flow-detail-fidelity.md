# Flow 1–2 detail fidelity, third derivative batch

This batch follows the published Flow node/run milestone and the separately frozen inspector Tabs batch. It corrects measured Flow 1–2 consumer details; Flow 3–4 receive only the shared mobile inspector font-family boundary. It does not establish complete visual parity for all Flow blocks.

## Reference and scope

Reference observations use public rendered `https://reui.io/preview/base/flow-1?embed=1` and `flow-2?embed=1`, fresh default light pages, 1440×900 and 390×900, DPR 1, zoom 100%. They use rendered DOM/computed styles and interactions, without fetching Pro source or distributing reference artwork. Private captures remain under `/tmp`.

Three conspicuous differences in the preceding candidate were the Flow 1 Success badge icon growing from 12px to 16px, Flow 2 node menus opening at 128px/start instead of 176px/end, and mobile inspector text escaping its Inter font boundary. Further checks identified incorrect Pan dragging, a false initial Snap state and nested Escape dismissal.

## Reuse and custom boundary

Actual reused components are Frame/FramePanel, Badge, IconTile, Card, Separator, Toggle, Tooltip, Button, DropdownMenu/CheckboxItem/Separator, ContextMenu/Separator, ToggleGroup/ToggleGroupItem and the existing Sheet/Select. Existing inspector Tabs/period controls are inherited from the separate Tabs milestone, not counted as new work here.

React Flow remains the canvas engine because the free ReUI library does not provide that graph engine. Graph fixture, viewport/mode/snap rules and the instance-local portal font bridge are domain/host integration; they do not replace available free components. Original Bricklane branding and local artwork remain; MIT, font OFL and asset attribution records are preserved.

Source routing remains the actual `flow-gantt-flow.tsx` entry. Its imported font bridge and existing node/Tabs leaves must be recursively present in source browsing and downloads. No route split or mapping change is needed.

## Per-entry ledger

### 4 — Ranked Scorecards

Public brief: six products, three per page, overall0–10 ranking, five dimension bars, best-in-class highlighting, wins, top-pick corner treatment, ratings and cart. Overall is stored independently rather than calculated from dimensions. The reference's cart only logs and its methodology link lacks a target.

Implementation: two actual native Carousel pages, each containing three ranked Frame scorecards. Desktop has three columns; phone stacks each page's three cards. Overall values sort the models independently of five score dimensions. Native Progress indicators highlight each dimension maximum across all six; wins count those exact maxima. One leader has the Top pick Badge at its upper corner. Native arrows, dots, keyboard and drag change pages. Inactive page controls cannot be focused. Cart is fully local and survives page changes. How we score opens an accessible actual free DialogSurface and explicitly states that products, scores and testing are fictional; it does not claim 50 real test hours.

Remaining: original rendered spacing, corner-ribbon geometry, mobile paging choice and exact test-score distribution are unverified. Original product photography and brand are intentionally replaced. The top-pick Badge is not claimed as an exact diagonal-ribbon recreation.

### 5 — Alternatives Switcher

Public brief: one focused hero and three stacked rivals with price deltas, ratings, feature checklists and Switch. Hero cart has no original handler. Original hi-res inference recognizes only LDAC/aptX HD.

Implementation: actual stacked Frame focal card beside three actual outline Item rivals. Four fictional models form the switchable set; switching changes the hero identity, image, price, ratings, six feature rows, cart action and all three rivals. The previous focus becomes an alternative, and signed price deltas are recalculated. Reset restores Field Pro while retaining cart records. Hi-res uses the existing explicit typed boolean; it does not silently infer capability from arbitrary codec names.

Remaining: the reference's exact four identities, image treatments, spacing and expanded/mobile appearance are not visually verified. The local four-model subset and real cart are explicit demo adaptations. All six shared models remain available in4 and6.

### 6 — Compare Builder

Public brief: six-model catalog, native compare toggles, up to four slots, dashed empties, selected count, Clear all and a live spec panel. Starts with two selected; numeric winners apply only at two or more models with a declared direction.

Implementation: six Frame cards with actual controlled c-toggle-10 label/icon state. Field Pro and Studio Max start selected; selection caps at four and disables only unselected models. A pressed Toggle or slot Remove releases capacity, Clear all empties every slot, and the four real slots remain visible. Actual DataGrid renders the existing thirteen grouped specifications, with native pinned labels and internal horizontal scrolling on narrow screens. Numeric direction is lower price/weight/charging, higher battery/rating. Equal-only rows and singleton selections have no winners; tied best values may both lead when other values differ. Boolean/text values are never numerically ranked. Clearing or removing the comparison preserves cart contents.

Remaining: the original desktop/mobile visual arrangement is unverified. Using the actual free DataGrid is an intentional implementation improvement over hand-built slot rows; native scrolling, focus and pinning remain real. The catalog, values and illustration set are fictional.

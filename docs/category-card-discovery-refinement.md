## Scope and evidence level

The public [Category Card index](https://reui.io/blocks/ecommerce/category-card.md) lists **six entries**, matching the repository catalog's exact names and indices. All six official public Markdown briefs were read. This milestone implements only entries 1–3 in independent modules; entries 4–6 remain audited but pending refinement. No paid source or premium media was retrieved.

**Public rendered desktop, mobile, hover and interaction comparison remains pending.** Browser screenshot connections are unavailable and the user is actively using Edge; this batch does not compete for the foreground browser. Metadata and official free-source review are not labeled visual verification. Local screenshots verify only our implementation.

## Free-library gaps and independent demo data

The free registry provides the presentation/interaction capabilities above; it does not supply an eight-collection Bricklane taxonomy or this catalog's combined search/facet/sort/page computation. Custom code is restricted to that domain data, pure filtering/sorting and grouped-page metadata; keyboard, focus, disclosure, selection, switch and carousel mechanics remain the real free implementations.

Four departments each contain fifteen independently illustrated sample pieces. Four overlapping curated edits combine those existing departments into 30/30/30/60 piece collections. They intentionally overlap and should not be summed as a unique inventory total. Collection availability, fit tags and badges are fictional editorial metadata. There are exactly three badges, and featured-only uses the presence of those badges rather than a disconnected flag.

All imagery directly consumes existing local original `wishlistArtwork`; no upstream photography, avatar, decorative SVG, screenshot, brand mark or paid asset is loaded. Bricklane is an independent original sample. Actual official REUI MIT, shadcn MIT, project license and font OFL notices remain transitively included in downloaded projects.

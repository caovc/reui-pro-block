Existing free Dialog / Input / Label / Button primitives handle the local share, restock, browsing and bag dialogs. These supplement missing domain capabilities: free REUI has no ready-made saved-product store, wishlist-to-cart mutation, inventory model, JSON-list export or email-delivery backend. The domain state is ordinary React state. No raw replacement of existing DataGrid selection, tab keyboard behavior, alert, badge, field or dialog mechanics was introduced.

## Media and local behavior

`wishlist-artwork.ts` contains fifteen original product drawings from basic geometric SVG shapes, composed through the existing `svgImage` helper. No tracing, downloaded upstream source or commercial asset is used. Their garment, bag, leather-good and home-object silhouettes match the item type but intentionally do not reproduce the public photos. `wishlist-data.ts` keeps each entry's own names, prices, availability and counts; boards and rails are prepared as actual arrays for the following independent batch, including twelve records across the four rail collections.

Local bag state is shared within each mounted demo, with stock-aware quantities, removal and totals. Share copies the current page link and downloads current product data as JSON; it does not upload a list. Restock forms keep a local email alert, display that limitation and support turning the alert off. Reloading resets demo state. Browsing can save genuinely new items, and counts and selection respond to the new arrays.

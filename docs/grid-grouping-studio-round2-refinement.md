Both entries now reproduce their observed filter, Display, density, summary, section band, header, cell, empty and action compositions. ## Actual free components and custom gaps

Both leaves compose the installed free `Frame`, header/title/description/panel, `Badge`, `DataGrid`, container, table, native headers and cells. `useDomainGrid` creates a real `useTable({ features: dataGridFeatures })` instance from `@tanstack/react-table`; filtering, sorting, visibility and selection operate on raw records. Editorial uses the official `DataGridScrollArea`. Delivery uses the installed free `ScrollArea` and `ScrollBar`. Both retain genuine inner horizontal scrolling.

The remaining controls use the same installed free primitives: InputGroup, ToggleGroup, DropdownMenu checkbox items, Popover, Field/FieldGroup/FieldSeparator, Select, Switch, Button, AvatarGroup and Empty. Delivery also uses AvatarGroupCount and Tooltip. The generic free visibility component lacks the observed density/metadata/property-pill composition, so these consumer controls compose the existing primitives and update native column visibility. No table, filter or sorting engine is recreated.

Story/stage partitioning, null-aware completion averages, Unchecked counts, stable crew records and the eight-segment business progress display are custom domain work absent from the generic table. The installed free Progress was also checked: it renders one continuous Indicator and exposes no segmented-track API, so the measured eight-segment cell remains a small domain renderer. Informational New story/Add story/row actions and missing-name/brief affordances reproduce public demo toasts. The existing local Move to ready action remains an explicit extension: it moves selected records to Ready To Ship/100% and clears selection; it is not claimed as public behavior or backend persistence.

Avatars are original `demoAvatar` artwork. Delivery client tiles use original typographic artwork rather than upstream brand SVGs. Free component MIT and font OFL notices remain in the source/download closure. Shared components, vendor DataGrid, global CSS, Tabs and other chats' files are outside this payload.

## Implementation

- The existing actual Card / CardHeader / CardTitle / CardDescription / CardAction composition now presents risk as an accessible level-three heading, then the original local customer, then workload or missing material. Existing free ReUI Badge renders the status icon next to customer identity. The surrounding actual free Frame is retained.
- Past-due cards use the existing `jobProgress(job).left`; lost-day cards use the existing `taskHours(day)`; missing-delivery cards show that material's name. Current original local records therefore display `23h left`, `31h left`, `8h` and `Quartz countertop`. Reference fixture values `26h` / `20h` are not copied into unrelated local records. Non-weather lost days receive a generic lost-day heading rather than a false rain label.
- The card minimum width is 274px so risk text and its existing text action can fit together on phones. The region retains its internal horizontal scrolling and snap behavior. Card body typography and spacing come from the installed components.
- Existing `View`, `Make Up` and `Set Date` callbacks, exact accessible action names and opener focus handling are retained. Attention continues to receive all schedule jobs; search/filter behavior is unchanged.
- The header displays the actual `crew.length` and can wrap on narrow screens.

The official free `c-card-1` registry example was inspected at `https://reui.io/r/radix-nova/c-card-1.json`; it explicitly depends on the upstream `card` and `button` components and uses the same Card slots. Existing official free Badge and Frame implementations were read locally. No duplicate primitive, external portrait, paid screenshot or extracted SVG is added. The risk aggregation, workload content and local task actions remain application-specific composition.

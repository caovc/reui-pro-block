## Authorized new upstream dependency

ReUI's free Navigation Menu page explicitly prescribes upstream shadcn NavigationMenu. This component did not exist in the project. Root authorized exactly one new file, with no overwrite or package/lock changes.

- Official CLI `add navigation-menu --dry-run` reported one new file and the existing `cn` dependency. `cn`, `radix-ui`, `class-variance-authority` and Lucide were already installed, so no dependency installation was required.
- CLI `add navigation-menu --view src/components/ui/navigation-menu.tsx` provided the actual 164-line radix-nova implementation. Its raw extracted source SHA256 is `8fd557c15579a89ebe72bd8fbf71741c86aa5071b78b685d157f9e69b828ef24`.
- New `src/components/ui/navigation-menu.tsx` retains that Root/List/Item/Trigger/Content/Viewport/Link/Indicator and style implementation. Only the `cn` import is mechanically mapped to existing `@/lib/utils`; provenance comments are added and oxfmt normalizes formatting. No hover, pointer grace, focus management or viewport behavior was rebuilt.
- [Official shadcn docs](https://ui.shadcn.com/docs/components/radix/navigation-menu) and [Radix API](https://www.radix-ui.com/docs/primitives/components/navigation-menu) were fetched and examined. The one oxlint Fast Refresh warning comes from the unchanged upstream file exporting its shared trigger-style constant with components; there are no lint errors.

## Custom gaps, brand and state boundaries

The free library has no complete combined marketing header or invoice-editor close/review bar. Custom code is limited to header layout/responsive wrapping, original domain fixtures and local navigation/review/preview state around actual free implementations. No existing available free behavior is replaced by a hand-drawn menu, toggle, spinner or animation.

The only graphic brand is the repository's original Bricklane mark. Lucide is used for all product/company/control glyphs. No REUI/KeenThemes logo, original-site portrait, screenshot, decorative image or extracted SVG is loaded or exported. Provider names from other navbar batches are not used here. Existing MIT/OFL/third-party notices remain part of project/starter export.

Neither demo sends a message, submits an invoice, routes to a paid financial product, creates an account or performs remote review. Data lasts only for this mounted preview; reload resets it. The copy action writes only the displayed original fixture summary. Exact original spacing, typography/breakpoints, company/product names and live expanded-menu geometry remain unverified pending original rendered evidence.

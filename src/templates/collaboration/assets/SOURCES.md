# Asset provenance

The collaboration demo portraits and wallpaper illustrations are original, locally authored SVG artwork generated by [demo-artwork.ts](../../../lib/demo-artwork.ts):

- [photo-assets.ts](../photo-assets.ts) creates 18 seeded portraits with `demoAvatar()`.
- [wallpaper-assets.ts](../wallpaper-assets.ts) creates 75 abstract dashboard illustrations with `demoPanel()`.

The shared collaboration avatar and Pulse promo also use these generators. `svgImage()` encodes their inline SVG as `data:image/svg+xml` URLs; these illustrations do not require requests to an external image host. See [THIRD_PARTY_NOTICES.md](../../../../THIRD_PARTY_NOTICES.md) for the existing original-artwork statement and separate dependency notices.

Official preview links retained in the catalog and documentation are historical comparison references, not the source or license of these generated illustrations. These portrait and wallpaper collections do not load or redistribute ReUI-hosted avatars, premium screenshots, or decorative SVG media extracted from the reference previews.

Template source downloads include the generator through its imports and include this family attribution through [source.ts](../../source.ts). The SVG images are generated from that source; no original preview image binaries are needed for these collections.

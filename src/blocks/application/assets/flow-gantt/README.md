# Flow / Gantt original demo portraits

All displayed portrait artwork is generated locally by `demoAvatar` in `src/lib/demo-artwork.ts`, using fictional demo names as deterministic seeds. No portrait requests are sent to ReUI or external image hosts.

Previously matched reference-preview photographs were removed under the project original-media policy. Initials fallbacks and accessible person names remain unchanged. The source download includes the original helper through its normal transitive dependency resolution.

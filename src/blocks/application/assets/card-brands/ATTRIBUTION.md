# Public brand marks used in Card 1–15 previews

SVGs are from the **Simple Icons** open-source collection (CC0-1.0):
https://github.com/simple-icons/simple-icons
https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

Retrieved 2026-10-22 from the official npm package through jsDelivr, with GitHub's upstream repository as a retry source. Brand fill colors were applied locally. Names included: Resend, Stripe, Supabase, OpenAI, Anthropic, PayPal, Discord, Redis, App Store, MongoDB and Solana.

No paid REUI assets or registry source were retrieved. All trademarks belong to their respective owners. A Lucide Flame is used as a visual substitute for Hotmart. The Partner Showcase uses approximate brand chips; several differ from the public REUI example.

People photos are existing public replacement assets in the parent application/assets directory; see that directory's README.md for attribution. Mara Alves uses a replacement photo, not the public preview's original portrait.
